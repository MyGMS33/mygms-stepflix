À propos des calories

CAL L20 est conservé exactement comme affiché par le tapis. Estimation StepFlix est calculée séparément avec durée, distance, inclinaison et poids. Elle reste une estimation physiologique, pas une mesure directe.

Architecture

Version GitHub Pages actuelle : les séances et paramètres sont enregistrés localement sur ce téléphone dans le navigateur. Rien n’est envoyé à GitHub. Utilise régulièrement Exporter mes données pour garder une sauvegarde. Le backend FastAPI/SQLite reste dans le dépôt pour une future synchronisation serveur.
